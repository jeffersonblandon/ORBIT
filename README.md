# 🚀 ORBIT

ORBIT es una plataforma de comercio electrónico especializada en productos tecnológicos, diseñada para ofrecer una experiencia de compra moderna, rápida y segura mediante un modelo de Dropshipping.

---

# 🎯 Objetivo

Construir una plataforma escalable que permita vender productos tecnológicos sin necesidad de mantener inventario propio, integrando proveedores de Dropshipping y ofreciendo una excelente experiencia de usuario.

---

# 🛠 Tecnologías

## Frontend

- React
- Vite
- TypeScript
- Tailwind CSS

## Backend

- Node.js
- Express
- TypeScript
- Prisma ORM
- PostgreSQL
