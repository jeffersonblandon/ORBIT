# ORBIT - Modelo de Negocio

## ¿Qué es ORBIT?

ORBIT es una plataforma de comercio electrónico especializada en productos tecnológicos. Su objetivo es ofrecer una experiencia de compra moderna, rápida y confiable, utilizando un modelo de Dropshipping para ampliar el catálogo sin necesidad de mantener inventario propio.

---

## Modelo de Negocio

ORBIT funciona bajo el modelo de **Dropshipping**.

Esto significa que:

1. El cliente realiza una compra en ORBIT.
2. ORBIT recibe el pago y procesa el pedido.
3. El proveedor recibe la orden.
4. El proveedor envía el producto directamente al cliente.
5. ORBIT obtiene una ganancia por la diferencia entre el precio de compra al proveedor y el precio de venta al cliente.

## Objetivos

### Corto plazo

- Lanzar la plataforma.
- Tener un catálogo funcional.
- Integrar al menos un proveedor de Dropshipping.

### Mediano plazo

- Automatizar pedidos.
- Implementar múltiples proveedores.
- Integrar diferentes métodos de pago.

### Largo plazo

Convertir ORBIT en una de las plataformas de tecnología más importantes de Latinoamérica.
